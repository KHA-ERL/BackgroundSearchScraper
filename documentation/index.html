Getting Started

Thank you for purchasing BubbleScraper! Setup takes just a few minutes. Install dependencies, build, start — and you're scraping.

Quick Setup (3 Steps)

  1. Install dependencies with npm
  2. Build the application
  3. Start the server and open it in your browser

Detailed instructions below. The whole process takes about 5 minutes.

Step 1: Install Dependencies

Requirements

  • Node.js 18 or higher. Check with node -v
  • npm 9 or higher. Check with npm -v

No separate browser install needed. Playwright downloads its own Chromium.

Open a terminal in the project folder and run:

npm install

npx playwright install chromium

Step 2: Build & Start

npm run build

npm start

Open http://localhost:3000 in your browser. That's it. You're ready to scrape.

Setup complete! Start scraping.

Configuration (Optional)

BubbleScraper works out of the box with zero configuration. For advanced options, copy the example config file:

# Mac / Linux

cp .env.local.example .env.local

 

# Windows

copy .env.local.example .env.local

You can also configure everything from inside the app at Dashboard → Profile → Settings.

Setting What it does
MISTRAL_API_KEYPowers the Agentic AI Terminal. Required to process natural language chat instructions and autonomously route them to the correct scraper tools.
DNS_MODEUse OS/VPN DNS (default: vpn) or encrypted DNS-over-HTTPS (doh)
BRIGHT_DATA_ENABLEDRoute scrapers through Bright Data residential proxies (bypasses bot blocks)
LISTCLEAN_API_KEYFull SMTP email verification. Without it, free DNS check is used.
WEBHOOK_URLAuto-POST results to Zapier / Make / n8n after every scraper run

Keep It Running (Production)

Use PM2 so the app survives terminal closes and server reboots:

npm install -g pm2

pm2 start npm --name "bubblescraper" -- start

pm2 save && pm2 startup

To restart after changes:

pm2 restart bubblescraper

To view logs:

pm2 logs bubblescraper

WordPress Integration

Optional Addon

Want to use BubbleScraper inside WordPress Admin? The BubbleScraper WordPress Addon is available as a separate purchase on CodeCanyon. It embeds this dashboard as a native WordPress Admin page.

How it works

  1. Install & start this BubbleScraper app on your server
  2. Install the WordPress Addon plugin
  3. Enter your app URL in the plugin settings (e.g., https://app.yourdomain.com)
  4. Use all 33 tools directly from your WordPress sidebar

Nginx / Reverse Proxy

If your app runs on a different port or server from WordPress, you may need to proxy it. Make sure iframe embedding headers are set:

location /scraper/ {

  proxy_pass http://127.0.0.1:3000/;

  proxy_set_header Host $host;

  proxy_http_version 1.1;

  # Allow iframe embedding

  add_header X-Frame-Options "";

  add_header Content-Security-Policy "frame-ancestors *";

}

Frequently Asked Questions

What are the server requirements?

Node.js 18+ and npm 9+. 1 GB RAM minimum, 2 GB recommended. Works on any Linux, macOS, or Windows server.

How many websites can I scrape?

There are no per-query limits. Scrape as many websites as you need. The only limit is your server's resources.

Do I need to install a browser?

No. The npx playwright install chromium command downloads a dedicated Chromium browser automatically. No system browser needed.

Some scrapers return empty results. What do I do?

Most tools work out of the box. For stubborn sites with bot detection, enable Bright Data in Dashboard → Profile → Settings. This routes scrapers through residential proxies.

Can I use this with WordPress?

Yes! The BubbleScraper WordPress Addon (sold separately) embeds the full dashboard inside WordPress Admin. See the WordPress Integration section.

How do I keep the app running after closing the terminal?

Use PM2. See the Production section for setup instructions.

What keyboard shortcuts are available?

Cmd+K / Ctrl+K: Open command palette (jump to any tool)
↑ ↓ Enter: Navigate and select
Esc: Close

Troubleshooting

Port already in use

lsof -ti:3000 | xargs kill -9

npm start

Browser not found

npx playwright install chromium

Clean reinstall

rm -rf node_modules .next

npm install && npm run build
